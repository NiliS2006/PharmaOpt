# Held-out synthetic benchmark

Generated by `backend/benchmark.py`: 100 independently seeded synthetic pharmacies per budget, 90-day evaluation horizon, and 95% normal confidence intervals across pharmacies. The planning engine sees only each pharmacy's 42-day sales history and current stock. Evaluation uses a separate stochastic demand path with weekly variation, trend, random demand noise, and occasional spikes; the future path is not used to make the plan.

Opening stock is generated as 12–35 days of each item's own demand, split into dated batches. A minority of batches have near-term expiry. Items have item-specific costs, lead times, and demand levels. Orders arrive after supplier lead time; all methods use the same FEFO/lost-sales simulation and ₹ budget cap. Each plan places one order at the start; there is no replenishment or reforecast during the horizon. Baselines are a reorder-point (s,S) rule and an order-up-to-30-days rule. Results are averages per pharmacy; intervals are 95% confidence intervals for those means. Stockout medicine-days sums the number of days each medicine had unmet demand. The unchanged expiry totals reflect current batches expiring independently of the one-time order decision; the 90-day trial does not establish that any method reduces expiry.

*Lost-sales value is unmet units multiplied by acquisition unit cost: a comparable proxy, not measured retail revenue or profit. Expiry value is expired units multiplied by acquisition cost. No real pharmacy data is included; this benchmark supports synthetic comparisons only and is not evidence of real-world impact.*
